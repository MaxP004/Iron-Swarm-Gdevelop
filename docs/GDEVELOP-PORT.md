# Iron Swarm в GDevelop

## Версия 1.2.0 (по отзывам игроков gd.games)

- **Переключатель скорости 1x/2x** — кнопка справа от шестерёнки настроек. Выбор сохраняется в настройках (`speed`). На 2x за кадр выполняются два обычных шага логики (`advance` в `src/game/session.ts`), поэтому столкновения и таймеры считаются с прежней точностью. Пауза, автосохранение и интерфейс работают в реальном времени.
- **Индикатор загрузки.** Ресурс `IronSwarmPackage` больше не предзагружается движком (`disablePreload`): загрузчик сцены скачивает его сам и показывает процент и мегабайты. Если данные не поступают 15 секунд, выводится предупреждение и кнопка «Повторить». При сетевой ошибке — сообщение и повтор. Если игра скачалась, но за 30 секунд не сообщила о запуске (`iron-swarm:ready`), появляется подсказка с кнопкой обновления страницы. Тексты загрузчика выбираются по сохранённому языку игрока или языку браузера.
- Внутри игры экран загрузки показывает процент подготовки текстур.
- Проверка: 48 модульных тестов (добавлены тесты скорости и настройки `speed`), браузерная проверка экспорта, ручная проверка медленной и прерванной загрузки. Копия файлов версии 1.1.0 — `backup/1.1.0`.

Перенос подготовлен 9 ноября 2026 года. Основа — браузерная версия 1.1.0 из `D:/IronSwarmPort`.

## Устройство

`game.json` — проект GDevelop 5 с первой сценой `IronSwarm`. Событие JavaScript однократно запрашивает JSON-ресурс `IronSwarmPackage` через штатный `JsonManager` движка и открывает упакованную игру в окне iframe на весь экран игры. Встроенный документ наследует адрес происхождения экспортированной игры. Это сохраняет обычные браузерные сохранения и управление.

Пакет самодостаточен: все 63 файла из `public/assets` встроены как data URL. В него входят оригинальные стили, шрифт, графика, музыка, звуки и один JavaScript-бандл. Доступ к исходной папке или к стороннему сайту во время игры не требуется. При выгрузке сцены GDevelop удаляет окно игры. При ошибке чтения пакета доступна повторная попытка загрузки.

При первоначальном переносе исходники в `src` были сохранены без изменений. Адаптер сборки меняет способ получения ресурсов и чтение параметра `?dev` из адреса внешнего документа. Последующие изменения интерфейса описаны выше; формулы боя, расписание волн, экономика и формат сохранений не переписывались.

Это выбранный перенос с сохранением кода. Сцена конструктора не содержит визуальных объектов игры, а боевые механики не представлены обычными событиями GDevelop. Для изменения логики используется TypeScript с последующей командой `npm run build:gdevelop`.

## Публикация

Откройте `game.json` в GDevelop, запустите предпросмотр, затем используйте **Share → gd.games → Publish game**. Удалять ресурс `IronSwarmPackage` нельзя: ссылка на него находится в JavaScript. Весь пакет передаётся при экспорте как обычный JSON-ресурс проекта.

После получения ссылки проверьте звук после первого клика, полноэкранный режим, сохранение после обновления страницы и сенсорное управление. Прогресс хранится локально в браузере. Автоматический перенос между адресами и облачная синхронизация не реализованы; кнопки импорта/экспорта удалены.

Официальная инструкция: [Publishing your game on gd.games](https://wiki.gdevelop.io/gdevelop5/publishing/web/).

## Пересборка

1. Измените исходники или ресурсы.
2. Выполните `npm test` и `npm run build:gdevelop`.
3. Для локальной проверки выполните `npm run export:gdevelop`, `npm run build`, затем `npm run test:browser`.
4. Снова откройте проект или обновите его в GDevelop и запустите предпросмотр.

Экспортный скрипт читает компилятор из установленного GDevelop и записывает результат только в папку проекта. Программа GDevelop и исходный проект `D:/IronSwarmPort` не изменяются. `GDEVELOP_HOME` позволяет указать другую папку установки.
