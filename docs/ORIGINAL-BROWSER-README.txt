Iron Swarm — Железный Рой
Версия 1.1.0

Iron Swarm — одиночная игра с автоматическими боями и постоянной прокачкой.
Игрок защищает короля от оживших клинков, покупает улучшения за золото
и открывает постоянные перки за алмазы. Основная цель — пройти 100 волн.
После финальной битвы можно продолжить в бесконечном режиме.

Первый вариант игры был сделан в Unity. Эта версия перенесена в браузер:
логика написана на TypeScript, отрисовка работает через PixiJS,
а меню и остальные элементы интерфейса сделаны на HTML и CSS.

Как запустить

1. Установить Node.js, если его ещё нет на компьютере.
2. Открыть терминал в папке проекта и выполнить npm ci.
3. Выполнить npm start или запустить Start-IronSwarm.cmd.
4. Открыть http://127.0.0.1:5173/.

Если зависимости уже установлены, второй шаг можно пропустить.
Для остановки локального сервера нужно нажать Ctrl+C в его терминале.

Управление

Бой идёт автоматически. Улучшения покупаются на панели справа.
После объяснения Хрономанта на 21-й волне открывается дерево навыков.
Кнопка дерева находится справа внизу арены.

Настройки открываются шестерёнкой слева под номером волны или клавишей Esc.
Повторное нажатие Esc закрывает настройки. Если открыто подтверждение
покупки или возврата, сначала закроется оно.

Меню настроек и дерево ставят игру на паузу.
Закрытие настроек поверх дерева возвращает к дереву, не возобновляя бой.

Способности открываются после покупки основных перков.
Их можно включать кнопками под здоровьем короля или клавишами 1, 2 и 3.
При открытии первой способности Король объясняет её действие.

F5 — сохранить игру.
F8 — загрузить последнее сохранение.

Сохранения и настройки

Прогресс автоматически сохраняется каждые 15 секунд и при закрытии страницы.
Ручное сохранение, импорт и экспорт JSON находятся в настройках.
Звук, музыка и язык сохраняются отдельно от прогресса.
Новая игра требует подтверждения и не сбрасывает громкость или язык.

Сохранение привязано к адресу сайта и браузеру.
Перед переносом игры на другой адрес или в другой браузер нужно экспортировать
JSON, а затем загрузить его через импорт. Поддерживаются и сохранения из Unity.

В настройках можно описать ошибку и скачать отчёт о текущем запуске.
В него входят версия игры, волна, FPS и сообщения ошибок.
Отчёт остаётся у игрока, пока он сам не передаст файл разработчику.

Устройство проекта

src/game/state.ts         — данные игрока и начальные значения.
src/game/progression.ts   — улучшения, цены и зависимости перков.
src/game/combat.ts        — враги, атаки, попадания и монеты.
src/game/waves.ts         — расписание появления врагов.
src/game/abilities.ts     — длительность и восстановление способностей.
src/game/session.ts       — ход игры, диалоги, смерть и возврат.
src/view/world.ts         — игровая сцена PixiJS.
src/view/ui.ts            — основной интерфейс.
src/view/settings.ts      — меню настроек.
src/view/layout.ts        — расположение здоровья и кнопок способностей.
src/platform              — звук, сохранения, настройки и отчёты.
src/data                  — баланс, локализация и разметка.
public/assets             — графика, музыка, звуки и шрифт.
tests                     — автоматические проверки.

Проверка и сборка

npm test          — автоматические тесты.
npm run build     — проверка TypeScript и сборка игры в dist.
npm run preview   — просмотр собранной версии.
npm run benchmark — замер скорости игровой логики без графики.

Для создания архива после сборки:
powershell -File scripts/package-release.ps1

Браузерная сборка находится в releases/IronSwarm-web-1.1.0.zip.
Внутри архива index.html лежит в корне. Игра подготовлена для размещения
на Newgrounds; порядок загрузки описан в docs/RELEASE-GUIDE.txt.
Открывать сборку двойным кликом через file:// не нужно — требуется веб-сервер.

Документы по практике

docs/CASE-3-UI.txt         — интерфейс.
docs/CASE-4-TESTING.txt    — тестирование и оптимизация.
docs/CASE-5-RELEASE.txt    — подготовка выпуска и работа с отзывами.

Интерфейс сохраняет пропорции 16:9. На телефоне удобнее играть горизонтально.
Основные проверки выполнены в Windows; полный прогон на Android и iOS ещё нужен.
